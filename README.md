# Circuit FD — دریافت بازی

نسخهٔ مستقل رانندگی، با خودروی زرد تقریبی الهام‌گرفته از RX-7 FD و پیست پارکی ۱٫۴۷ کیلومتری.

## دریافت

- [بستهٔ کامل ویندوز x64، حدود ۴۰ مگابایت](downloads/CircuitFD-Windows-x64.zip)
- [سورس کامل و دستور ساخت، حدود ۴٫۳ مگابایت](downloads/CircuitFD-Source.zip)
- [اندازه و SHA-256 فایل‌ها](downloads/SHA256.json)

در صفحهٔ هر فایل ZIP، گزینهٔ Download raw file را انتخاب کنید. بستهٔ ویندوز را کامل استخراج و CircuitFD.exe را اجرا کنید. راهنمای فارسی، تصاویر واقعی، گزارش آزمون، محدودیت‌ها و مجوزها داخل هر بسته قرار دارند.

۱۱۰ بررسی منطق/تعامل و آزمون یک دور کامل معتبر موفق بودند. EXE واقعی Windows x64 ساخته شده ولی اجرای بومی روی ویندوز واقعی و عملکرد GPU کاربر آزمایش نشده است. مدل خودرو سبک‌پردازی‌شده و تقریبی است؛ کیفیت فوتورئالیستیک یا AAA ادعا نمی‌شود.

کنترل‌ها: W گاز، S ترمز، A/D فرمان، Q انتخاب جهت حرکت، C دوربین، L چراغ، R بازگشت به شروع و Esc توقف.
